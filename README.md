# Mission 2027 — Control Center (`diagnostic-360`)

Local-first **Engineering Readiness Control Center** with **Diagnostic 360** as one module.

## Run

```bash
npm install
npm run dev
```

```bash
npm run lint
npm run test
npm run build
```

## Scope

- Overview dashboard, Today, Readiness (evidence-based)
- Full Diagnostic 360 (`/diagnostic`)
- IndexedDB workspace + localStorage diagnostic sessions
- Read-only Notion planning via `FixtureNotionAdapter` (live API: KHA-228)
